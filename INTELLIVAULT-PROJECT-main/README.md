# IntelliVault 🔐

IntelliVault is a full-stack web application designed to provide a secure, smart, and user-friendly platform for managing personal and organizational documents. It allows users to store, organize, retrieve, and share files efficiently while maintaining high levels of security.

## 🚀 Features

* Secure document storage
* Easy file upload and retrieval
* Organized document management
* User-friendly interface
* Scalable full-stack architecture

## ▶️ How to Run the Project

1. Clone the repository:
   git clone https://github.com/VKAparna066/INTELLIVAULT-PROJECT.git

2. Navigate to the project folder:
   cd INTELLIVAULT-PROJECT

3. Install dependencies:
   npm install

4. Start the development server:
   npm start

5. Open in browser:
   http://localhost:3000
